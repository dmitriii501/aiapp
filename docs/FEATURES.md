## 5. Управление ПК

Двухуровневая схема: LLM (System 2) планирует, быстрая модель решений (System 1, например Jev) выбирает действие на каждом шаге за доли секунды. Подробно — в [спецификации](specs/pc-control.md).

| Возможность | Приоритет |
|---|---|
| System 1 + System 2: план от LLM, пошаговые решения от модели решений, эскалация по уверенности | P1 |
| Адаптеры моделей решений: Jev, эмуляция на быстрой LLM | P1 |
| Политики решений: LLM пишет JSON-политику, System 1 исполняет её в цикле ([спека](specs/decision-policy.md)) | P1 |
| Рефлексы — правила без модели для срочных действий | P1 |
| Локальное восприятие для игр: OCR Windows, шаблоны экранов, полоски, пиксели | P2 |
| Игры: пошаговые, карточные, стратегии, меню (только одиночные / где боты разрешены) | P2 |
| Пересмотр политики LLM по логам решений, каталог политик | P2 |
| Кэш траекторий («мышечная память» агента) | P2 |
| Локальная модель решений (офлайн) | P2 |
| Окна: список, фокус, перемещение, размер, закрытие | P1 |
| Запуск приложений, открытие файлов / URL | P1 |
| Скриншоты экрана и окон | P1 |
| UI Automation: дерево элементов, клик по элементу, ввод текста | P1 |
| Мышь и клавиатура по координатам (computer use) | P1 |
| Буфер обмена | P1 |
| Системная информация: процессы, диски, сеть (только чтение) | P1 |
| Управление процессами (завершение) | P2 |
| Записанные сценарии / макросы («научи агента») | P2 |
| Голосовой ввод | P2 |
