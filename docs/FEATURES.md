## 5. Управление ПК

Двухуровневая схема: LLM (System 2) планирует, быстрая модель решений (System 1, например Jev) выбирает действие на каждом шаге за доли секунды. Подробно — в [спецификации](specs/pc-control.md).

| Возможность | Приоритет | Статус |
|---|---|---|
| System 1 + System 2: план от LLM, пошаговые решения от модели решений, эскалация по уверенности | P1 | ✅ `PcPursue`; шаг ~0,36 с |
| System 1 работает, пока System 2 думает: очередь фоновых запусков (`background`, `PcRuns`) | P1 | ✅ |
| Быстрая проверка «окно показывает то, что нужно» одним вопросом (`PcCheck`) | P1 | ✅ ~0,35 с |
| Порог уверенности по программам из журнала решений (`kairo pc stats`) | P1 | ✅ только поднимает порог |
| Адаптеры моделей решений: Jev, эмуляция на быстрой LLM | P1 | ◐ Jev есть; эмуляции на LLM нет |
| Политики решений: LLM пишет JSON-политику, System 1 исполняет её в цикле ([спека](specs/decision-policy.md)) | P1 | ◐ v0 для программ с деревом UI Automation (`PcRunPolicy`); игровая часть — нет |
| Рефлексы — правила без модели для срочных действий | P1 | ✅ внутри политики |
| Локальное восприятие для игр: OCR Windows, шаблоны экранов, полоски, пиксели | P2 | — |
| Игры: пошаговые, карточные, стратегии, меню (только одиночные / где боты разрешены) | P2 | — большая модель по скриншотам играет медленно; быстрой части для кадров нет |
| Пересмотр политики LLM по логам решений, каталог политик | P2 | — журнал есть, пересмотра нет |
| Кэш траекторий («мышечная память» агента) | P2 | — |
| Локальная модель решений (офлайн) | P2 | — |
| Окна: список, фокус, перемещение, размер, закрытие | P1 | ◐ список и фокус; перемещение, размер, закрытие — нет |
| Запуск приложений, открытие файлов / URL | P1 | ◐ `PcLaunch` по имени из PATH, App Paths и меню «Пуск» (оконные программы); файлы и URL — через Shell |
| Скриншоты экрана и окон | P1 | ✅ окна (`[pc] vision`) |
| UI Automation: дерево элементов, клик по элементу, ввод текста | P1 | ✅ стабильные id, изменения вместо дерева в больших окнах |
| Мышь и клавиатура по координатам (computer use) | P1 | ✅ по снимкам; сочетания клавиш и набор в сфокусированное |
| Буфер обмена | P1 | — |
