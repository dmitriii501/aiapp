## M1 — Агент в терминале (MVP ядра)
Цель: `kairo` CLI решает простую задачу в репозитории на любой из трёх моделей.
- [x] Провайдеры: Anthropic, OpenAI-compatible (OpenRouter, Ollama, LM Studio…) — с tool calling
- [ ] Нативный адаптер OpenAI Responses API и Gemini
- [x] Агентный цикл со стримингом и отменой
- [x] Инструменты: Read, Write, Edit, Glob, Grep, Shell (PowerShell; ConPTY — в M2 вместе с терминалом)
- [x] Разрешения ask / allow / deny, режимы default / acceptEdits / plan, конфиг `config.toml`
- [x] Сессии в SQLite (`-c`, `-r`), `AGENTS.md` / `CLAUDE.md`
- [x] CLI: интерактивный режим и `-p` для скриптов
- [ ] Набор eval-задач для регрессий на настоящих моделях
- [ ] Проверка на живых моделях (Claude, локальная через Ollama)

- [ ] Проверка на живых моделях
- [x] Дифф изменений в карточке подтверждения и в ленте (без Monaco)
- [ ] Принять / отклонить отдельные правки — вместе с чекпоинтами (M3)
