# Выпуск релиза

Решение и устройство обновлений — в [ADR-0005](adr/0005-velopack-installer-and-updates.md).

## Как выпустить версию

1. Убедитесь, что `main` собирается и тесты проходят (CI зелёный).
2. Поставьте тег и отправьте его:

   ```bash
   git tag v0.2.0
   git push origin v0.2.0
   ```

3. Workflow `.github/workflows/release.yml` соберёт приложение, упакует его через `vpk pack` и создаст релиз на GitHub с файлами:
   - `Kairo-win-Setup.exe` — установщик;
   - `Kairo-win-Portable.zip` — портативная версия;
   - `Kairo-<версия>-full.nupkg` и дельта-пакеты — их качают установленные копии;
   - `RELEASES`, `releases.win.json` — лента обновлений.
4. Установленные копии найдут версию при следующей проверке (через 30 секунд после запуска и раз в 6 часов) или по кнопке «Проверить сейчас».

Описание релиза строится из заголовков коммитов между тегами, поэтому пишите их как строки для пользователя (`feat:`, `fix:` по Conventional Commits).

До 1.0 релизы публикуются как обычные, без пометки pre-release: обновление ищет только обычные релизы.

## Что нужно один раз

- Репозиторий на GitHub и право workflow писать в релизы (`permissions: contents: write` уже в файле).
- Адрес ленты вшивается автоматически: `-p:KairoUpdateUrl=https://github.com/<владелец>/<репозиторий>`.
- **Подпись.** Без неё Windows SmartScreen предупредит при запуске установщика. Добавьте в шаг `Pack` параметр `--signParams` (сертификат) или `--azureTrustedSignFile`. Обязательно до публичной alpha.
- Защита тегов `v*` и двухфакторная защита аккаунта: пока пакеты не подписаны, именно они определяют, чему доверяют обновления.

## Проверка обновления вручную

Сборка из репозитория обновляться не умеет. Чтобы пройти путь целиком:

1. Опубликуйте версию 0.1.0 и упакуйте: `dotnet publish src/Kairo.Desktop -c Release -r win-x64 -p:Platform=x64 --self-contained -p:Version=0.1.0 -o publish`, затем `vpk pack --packId Kairo --packVersion 0.1.0 --packDir publish --mainExe Kairo.exe --outputDir Releases`.
2. Установите `Releases\Kairo-win-Setup.exe`.
3. Соберите и упакуйте 0.1.1 в ту же папку `Releases`.
4. Запустите установленную копию с `KAIRO_UPDATE_URL=<полный путь к папке Releases>` (папка работает как лента) и нажмите на версию в строке состояния.

## Отключение проверок

`%APPDATA%\Kairo\config.toml`:

```toml
[update]
check = false
```

Ручная проверка остаётся. Других обращений к сети для обновлений приложение не делает, телеметрии нет.
