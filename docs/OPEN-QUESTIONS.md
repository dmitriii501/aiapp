# Открытые вопросы

## Решено

| Вопрос | Решение | Дата |
|---|---|---|
| Название | **Kairo** (ещё проверить домен, GitHub, товарные знаки) | 2026-10-13 |
| Лицензия | **Apache-2.0** — см. [LICENSE](../LICENSE) | 2026-10-13 |
| Стек | **C# / .NET 10 + WinUI 3 + React/TS в WebView2** — [ADR-0001](adr/0001-tech-stack.md) | 2026-10-13 |
| Рой агентов | Входит в продукт: этап M4, [спецификация](specs/swarm.md) | 2026-10-13 |
| Язык документации | Внутренние доки на русском; перед публичным релизом переводим на английский (README — EN + RU). Код и комментарии — на английском | 2026-10-13 |
| Песочница для роя | Включена по умолчанию для воркеров (`[sandbox] shell = "workers"`); `git` у воркеров — инструмент `Git` только на чтение; git-операции роя в worktree идут по проверенному git-каталогу. См. [SECURITY-MODEL](SECURITY-MODEL.md#песочница) | 2026-10-14 |
| Автономность управления ПК | Два флажка пользователя: `[pc] autonomous` (без вопросов в режиме «Без подтверждений») и `[pc] all_apps` (любые программы, кроме запрещённых); оба только из пользовательского файла | 2026-10-14 |
| System 1 и System 2 вместе | Быстрый цикл работает в фоне, пока большая модель планирует (`background`, `PcRuns`); порог уверенности поднимается по журналу решений, не опускается; больше решений у Jev (риск, «по кругу», `PcCheck`) | 2026-10-14 |

## Не решено

Предложение — то, что выбрали бы по умолчанию.

| # | Вопрос | Предложение | Почему важно |
|---|---|---|---|
| 1 | ~~**Установщик и обновления**~~ | Решено: Velopack, см. [ADR-0005](adr/0005-velopack-installer-and-updates.md). Осталась подпись пакетов до публичной alpha | Первый опыт пользователя |
| 2 | **Native AOT для CLI** | Официальный Anthropic SDK не совместим с AOT (ADR-0001). Варианты: (а) CLI без AOT, нужен .NET runtime — сейчас так; (б) свой AOT-совместимый адаптер Anthropic на HTTP + SSE; (в) ждать AOT-поддержки в SDK. Предложение — (а) до M2, потом решить | Размер и холодный старт `kairo.exe` |
| 3 | **Генерация TS-типов из C#** | Tapper, TypeGen или свой source generator — решить в M0 | Синхронность UI и ядра |
| 4 | **Лимиты роя по умолчанию** | Например, 4 агента, $2, 30 минут — уточнить после экспериментов | Защита от случайных трат |
| 5 | **System 1 по умолчанию для управления ПК** | Включать по умолчанию, только если eval на русском и английском UI покажет точность не хуже «только System 2». Порог уверенности подобрать там же — [ADR-0002](adr/0002-pc-control-system1-system2.md) | Скорость vs надёжность |
| 6 | **Встроенный агрегатор** | После 1.0. Требует серверной части, биллинга и юрлица — это уже не просто open source | Модель монетизации |
| 7 | **Монетизация** (если нужна) | Бесплатный апп; опционально — платный агрегатор / облачные задачи | Стратегия |
| 8 | **Совместимость форматов** | Читать `CLAUDE.md`, `AGENTS.md`, `.claude/skills`, `mcp.json` Claude Desktop — максимум совместимости, свои форматы только где нужно | Лёгкая миграция пользователей |
| 9 | **Телеметрия** | Нет. Максимум — opt-in отчёты о падениях | Доверие |
| 10 | **Где хостить каталог** | GitHub-репозиторий `kairo-registry` + статический индекс | Без сервера на старте |
| 11 | **Минимальная Windows** | Windows 10 22H2+ и Windows 11 | WebView2, ConPTY, Graphics Capture |
| 12 | **Сеть в песочнице по списку адресов** | Сейчас сеть «всё или ничего»: без неё воркер не поставит пакеты, с ней — может отправить что угодно. Нужен список разрешённых адресов (реестры пакетов) через прокси или правила брандмауэра для контейнера | Воркеры, которым нужны зависимости, и безопасность |
| 13 | **Чтение вне worktree у воркеров** | `Read`, `Grep`, `Glob` работают вне песочницы и в режиме без подтверждений читают что угодно (`~/.ssh`), а `WebFetch` может это отправить. Варианты: ограничить чтение воркеров их worktree и `read`, запретить сеть воркерам при чтении вне | Утечка секретов из автономного роя |
| 14 | **Windows Sandbox / WSL как запасная изоляция** | Нужны, если AppContainer недоступен или нужен настоящий `git` и сеть внутри. Тяжелее, отдельное решение | Воркеры без инструмента `Git` |
| 15 | **Подпись пакетов** | Сертификат или Azure Trusted Signing до публичной alpha; сейчас SmartScreen предупреждает | Первое впечатление и доверие к обновлениям |
