# Видение

## Проблема

Лучшие AI-инструменты для разработки и работы за компьютером разбросаны и закрыты:

- **Claude Code** — сильный агентный цикл, но терминал и одна модель-семья.
- **Codex** — песочница и облачные задачи, но привязан к OpenAI.
- **Cursor** — отличный редактор и автодополнение, но закрытый, платный, привязан к своему бэкенду.
- Управление ПК, MCP, каталоги агентов — живут в отдельных утилитах и плохо дружат с Windows.

Пользователь Windows, который хочет **один** инструмент со **своей** моделью, сегодня собирает зоопарк.

## Что мы строим

Один открытый нативный Windows-апп, где:

1. Агентный движок не хуже Claude Code / Codex (инструменты, планирование, сабагенты, хуки, скиллы, чекпоинты).
2. Удобство редактора на уровне Cursor (дифф-ревью, inline-правки, индекс кодовой базы).
3. Агент умеет работать не только с кодом, но и со всем ПК — безопасно.
4. Большие задачи решает не один агент, а рой: параллельные агенты с ролями, общей доской задач и живой визуализацией.
5. Расширяемость через MCP и каталог готовых агентов и роёв.
6. Модель — любая: своя по ключу, локальная, позже — встроенный агрегатор.

## Для кого

- **Разработчики на Windows**, которым нужен агент для кода с выбором модели.
- **Продвинутые пользователи**, которые хотят автоматизировать рутину на ПК.
- **Авторы агентов и MCP-серверов**, которым нужна площадка для распространения.

## Принципы

1. **BYOK first.** Своя модель — основной сценарий, а не опция. Никакой обязательной регистрации и телеметрии.
2. **Безопасность по умолчанию.** Агент ничего опасного не делает без явного разрешения. Каждое действие видно и откатываемо.
3. **Windows — родная платформа, а не порт.** PowerShell, UI Automation, Credential Manager, WSL, Mica — как первоклассные граждане.
4. **Один движок — много интерфейсов.** GUI, CLI и headless-режим используют одно ядро.
5. **Открытые форматы.** Агенты, скиллы, конфиги — простые файлы (Markdown + YAML/TOML), совместимые с экосистемой где возможно (MCP, `AGENTS.md`, `SKILL.md`).
6. **Скорость и красота.** Холодный старт < 1 с, 60+ FPS анимации, UI не блокируется во время работы агента.

## Не-цели (пока)

- macOS / Linux — архитектура не должна мешать порту, но мы не тратим на это силы до 1.0.
- Свой форк VS Code. Встроенный редактор — для ревью и точечных правок, не полноценная IDE.
- Обучение собственных моделей.
- Платный маркетплейс. Каталог — бесплатный и открытый.
