# ADR-0004: Интерфейс — устройство Claude Code, оформление классического редактора

- **Статус:** принято
- **Дата:** 2026-10-13
- **Заменяет:** части ADR-0001 про Mica и выразительные анимации

## Контекст

Первая версия интерфейса была «витринной»: полупрозрачная Mica, пружинные анимации, крупные скругления. Это отвлекает от работы и требует постоянного внимания к мелочам. Изобретать собственные паттерны взаимодействия с агентом тоже незачем: в Claude Code они уже отработаны на большой аудитории.

## Решение

**Устройство — как у Claude Code:**
- лента с маркерами: `>` — сообщение пользователя, `●` — ответ агента или вызов инструмента `Tool(аргументы)`, под ним строка результата `⎿ …`, по клику раскрывается полный вывод;
- запрос подтверждения появляется на месте поля ввода; варианты «Да» / «Да, и не спрашивать до конца сессии» / «Нет», выбор цифрами 1–3, стрелками и Enter, Esc — отказ;
- Shift+Tab переключает режим разрешений, Esc прерывает работу агента;
- индикатор работы с таймером и подсказкой «Esc — прервать».

**Оформление — классический редактор кода (в духе VS Code):**
- панель активности, боковая панель с деревом «папка → сессии», вкладка сессии, строка состояния;
- сплошные цвета, границы в 1px, плотные строки по 22px, системные шрифты (Segoe UI, Cascadia Mono), один акцентный синий;
- светлая и тёмная темы по системе; заголовок окна — системный цвет WinUI, интерфейс совпадает с ним;
- анимации — только индикаторы состояния (мигающая точка, спиннер), без переходов и пружин.

Фирменный стиль, логотипы и тексты Anthropic не копируем — заимствуем только общие паттерны взаимодействия.

## Последствия

- (+) Интерфейс знаком разработчикам с первого взгляда, меньше решений «с нуля».
- (+) Меньше кода и зависимостей: убраны Mica и библиотека `motion`.
- (−) Меньше «вау-эффекта». Это осознанно: Kairo — рабочий инструмент.
