# Участие в проекте

Проект на этапе проектирования. Лучший способ помочь сейчас — обсудить документацию в `docs/` и открытые вопросы.

## Как предложить изменение

1. Создайте issue с описанием идеи или проблемы.
2. Для крупных архитектурных решений — добавьте ADR в `docs/adr/` (следующий номер, статус «предложено»).
3. Сделайте PR. Один PR — одно логическое изменение.

## Договорённости

- Ветки: `feat/...`, `fix/...`, `docs/...`.
- Коммиты: [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`…).
- Код и комментарии — на английском.
- Любая новая возможность, дающая агенту доступ к системе, обязательно описывает свой уровень риска (см. [SECURITY-MODEL](docs/SECURITY-MODEL.md)).

## Стек

Ядро и системная часть — C# / .NET 10, оболочка — WinUI 3, интерфейс — React + TypeScript в WebView2. Подробнее — в [ARCHITECTURE](docs/ARCHITECTURE.md).

## Где нужна помощь без знания C#

- UI и анимации (React/TS), карта роя
- Дизайн
- Агенты для каталога, скиллы, промпты
- Документация и переводы
- Тестирование на разных конфигурациях Windows
